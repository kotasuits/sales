Goal: Initialize a brand new, empty Firebase environment for your portal.
  1. Open the Firebase Console.
  2. Click + Add project (or Create a project).
  3. Enter your desired application name (e.g. EzyShip Portal) and click Continue.
  4. (Optional) Disable or Enable Google Analytics according to your preference, then click Create project.
  5. Wait for Firebase to configure resources, then click Continue to enter your project dashboard.
Goal: Set up Email/Password authentication and register admin/user accounts.
  1. In the left-hand navigation menu of the Firebase Console, go to Build > Authentication.
  2. Click Get started.
  3. Under the Sign-in method tab, select Email/Password.
  4. Toggle the first switch (Email/Password) to Enabled and click Save.
  5. Go to the Users tab in the Authentication dashboard.
  6. Click Add user, enter an email and password (e.g. admin@ezyship.com and a secure password), and click Add user. You will use these credentials to log into the application.
Goal: Setup Realtime Database to store shipments/billing logs and restrict access to logged-in users.
  1. In the left sidebar, click Build > Realtime Database.
  2. Click Create Database.
  3. Select your database location (choose the nearest region to your clients) and click Next.
  4. Select Start in locked mode (or test mode) and click Enable.
  5. Once the database is created, navigate to the Rules tab at the top.
  6. Replace the default database rules with the configuration below to configure public reading for tracking records while securing invoices, customer profiles, and setup parameters: 
    {
  "rules": {
    "records": {
      ".read": true,
      ".write": "auth != null"
    },
    "bills": {
      ".read": "auth != null",
      ".write": "auth != null"
    },
    "customers": {
      ".read": "auth != null",
      ".write": "auth != null"
    },
    "billingSettings": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
  7. Click the Publish button at the top of the editor.
Goal: Configure Firebase Cloud Storage bucket to securely upload and display tracking photos.
  1. In the left sidebar, click Build > Storage.
  2. Click Get started.
  3. Select Start in production mode (or test mode) and click Next.
  4. Choose your storage bucket location and click Done.
  5. Once the bucket is generated, click the Rules tab at the top.
  6. Replace the default storage rules with the secure config below: 
    rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  7. Click the Publish button to activate the rules.
Goal: Register a web client app and copy the credentials into this configuration panel.
  1. Click the Gear icon (Project Settings) next to Project Overview in the top left sidebar.
  2. In the General tab, scroll down to the bottom to the Your apps card.
  3. Click the Web App icon (</>).
  4. Enter an app name (e.g. EzyShip Web App), leave "Also set up Firebase Hosting" unchecked, and click Register app.
  5. Find the generated const firebaseConfig block. Copy the keys and paste them into the Firebase Credentials inputs above:
    • apiKey → API Key
    • authDomain → Auth Domain
    • databaseURL → Database URL
    • projectId → Project ID
    • storageBucket → Storage Bucket
    • messagingSenderId → Messaging Sender ID
    • appId → App ID
    • measurementId (if present) → Measurement ID
  6. Click Save for Preview to test live, or Download config file to save the changes permanently!
Goal: Deploy a Google Apps Script linked to your spreadsheet to log and query shipping records.
  1. Create a new Google Spreadsheet or open an existing tracking spreadsheet.
  2. Rename the active sheet/tab to Sheet1 or make sure it is the first tab in the spreadsheet.
  3. In the top menu, go to Extensions > Apps Script.
  4. Delete any placeholder code in the editor, and paste the code below: 
    function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var headers = data[0];
  var jsonArray = [];
  
  var colMap = {};
  headers.forEach(function(h, index) {
    colMap[h.toString().toLowerCase().trim()] = index;
  });
  
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    var record = {
      timestamp: row[colMap["timestamp"] || 0],
      pkgId: colMap["package id"] !== undefined ? row[colMap["package id"]] : (colMap["pkgid"] !== undefined ? row[colMap["pkgid"]] : ""),
      name: colMap["name"] !== undefined ? row[colMap["name"]] : "",
      phone: colMap["phone"] !== undefined ? row[colMap["phone"]] : "",
      pincode: colMap["pincode"] !== undefined ? row[colMap["pincode"]] : "",
      address: colMap["address"] !== undefined ? row[colMap["address"]] : "",
      rawText: colMap["rawtext"] !== undefined ? row[colMap["rawtext"]] : ""
    };
    
    if (record.timestamp instanceof Date) {
      record.timestamp = record.timestamp.toISOString();
    } else {
      record.timestamp = record.timestamp.toString();
    }
    
    jsonArray.push(record);
  }
  
  return ContentService.createTextOutput(JSON.stringify(jsonArray))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var params = e.parameter;
  
  if (params.action === "delete") {
    var timestampToDelete = params.timestamp;
    var data = sheet.getDataRange().getValues();
    
    for (var i = 1; i < data.length; i++) {
      var rowTime = data[i][0];
      if (rowTime instanceof Date) {
        rowTime = rowTime.toISOString();
      } else {
        rowTime = rowTime.toString();
      }
      
      if (rowTime === timestampToDelete) {
        sheet.deleteRow(i + 1);
        return ContentService.createTextOutput(JSON.stringify({
          status: "success",
          message: "Order deleted successfully"
        })).setMimeType(ContentService.MimeType.JSON);
      }
    }
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: "Order not found with timestamp: " + timestampToDelete
    })).setMimeType(ContentService.MimeType.JSON);
  }
  
  var payload = JSON.parse(params.data);
  var timestamp = new Date();
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Timestamp", "Package ID", "Name", "Phone", "Pincode", "Address", "RawText"]);
  }
  
  sheet.appendRow([
    timestamp,
    payload.pkgId || "",
    payload.name || "",
    payload.phone || "",
    payload.pincode || "",
    payload.address || "",
    payload.rawText || ""
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({
    status: "success",
    message: "Record appended successfully"
  })).setMimeType(ContentService.MimeType.JSON);
}
  5. Click the Save project (floppy disk) icon at the top of the editor.
  6. Click Deploy (blue button in top right) > New deployment.
  7. Click the Gear icon next to "Select type" and choose Web app.
  8. Configure deployment fields:
    • Description: EzyShip Sheets Link
    • Execute as: Me (your Google email)
    • Who has access: Anyone (CRITICAL for public submissions/reads)
  9. Click Deploy. If prompted, click Authorize Access, log in, expand "Advanced", and click Go to Untitled Project (unsafe) to grant permissions.
  10. Copy the generated Web App URL (e.g. https://script.google.com/macros/s/AKfycb.../exec).
  11. Paste this URL directly into the Google Sheets Web App URL input field under the Application Settings panel above.
